# Установка на iPhone

> Для установки **без компьютера и Expo Go** используйте выбранную веб-версию: [инструкция установки через Safari](INSTALL.md#iphone-установка-через-safari). Раздел Expo Go ниже предназначен для разработки. Нативная iOS-сборка всё ещё требует Apple Developer.

## Попробовать сейчас через Expo Go

Этот способ не требует платной подписки Apple Developer, но приложение открывается внутри Expo Go и ему нужен запущенный сервер разработки.

1. Установите Expo Go из App Store: https://apps.apple.com/app/expo-go/id982107779 . Нужна версия с поддержкой Expo SDK 58.
2. Скачайте актуальный проект с GitHub и распакуйте его. Установите Node.js 24 на компьютер.
3. На Windows дважды нажмите файл **`start-iphone.cmd`** в папке проекта. Он установит зависимости и запустит приложение. Либо откройте терминал в папке проекта и выполните `npm ci`, затем `npm start`.
4. Подключите компьютер и iPhone к одной Wi-Fi-сети. Отсканируйте QR-код из терминала камерой iPhone и откройте его через Expo Go. Разрешите доступ к локальной сети, если iOS спросит. Не закрывайте окно запуска на компьютере.

Веб-версия и Expo Go хранят данные отдельно. Записи из браузера автоматически не перенесутся.

## Отдельное приложение через TestFlight

Для подписанной версии нужны:

- аккаунт Expo / EAS Build;
- действующая платная подписка Apple Developer Program и доступ к App Store Connect с правами на приложение и подпись;
- принятые соглашения Apple. Пароли, коды 2FA и ключи не публикуйте в GitHub и не отправляйте в чат.

Сборка выполняется на серверах Expo; её можно запускать с Windows. Сам файл IPA не устанавливается на произвольный iPhone простым скачиванием.

### Подготовка аккаунта и проекта

В терминале в папке проекта:

```sh
npm ci
npx eas-cli@26.0.0 login
npx eas-cli@26.0.0 init
```

`init` связывает проект с вашим аккаунтом Expo. Поскольку используется динамический `app.config.js`, CLI может попросить добавить показанный им настоящий `extra.eas.projectId` в `app.json` вручную. Не подставляйте случайный ID. Если проект уже привязан к другому аккаунту, сначала проверьте права доступа.

В `app.json` задан первоначальный Bundle ID `com.raxnud1k.fitness`. При регистрации убедитесь, что он свободен или принадлежит вашей команде Apple. Если уже занят, выберите собственный уникальный ID до первой загрузки в App Store Connect. После публикации менять его для этого приложения нельзя.

### Собрать подписанный пакет

```sh
npx eas-cli@26.0.0 build --platform ios --profile production
```

При первом запуске войдите в Apple через официальный интерактивный процесс EAS, выберите команду и разрешите создание необходимых сертификатов и provisioning profile. EAS может предложить платный план или очередь: проверьте условия в своём аккаунте перед запуском платных операций. Профиль `production` использует подпись App Store и автоматически повышает номер сборки в EAS.

### Загрузить в TestFlight

Создайте приложение в App Store Connect с тем же Bundle ID, если оно ещё не создано. Дождитесь успешной сборки, затем выполните:

```sh
npx eas-cli@26.0.0 submit --platform ios --profile production --latest
```

Выберите нужное приложение и предоставьте необходимые права через официальный процесс EAS/Apple. После загрузки дождитесь обработки в App Store Connect → TestFlight и заполните запрошенные сведения. Для первой внешней группы обычно нужна проверка Apple Beta App Review. После её одобрения можно включить публичную ссылку приглашения либо пригласить тестировщиков по email. До этого публичной ссылки установки нет. Внутренние тестировщики должны иметь соответствующий доступ к App Store Connect.

На iPhone установите TestFlight из App Store и откройте полученное приглашение. TestFlight-сборки действуют ограниченное время (обычно 90 дней), затем нужна новая сборка.

## Что настроено и что ещё не проверено

Добавлены Bundle ID, начальный номер iOS-сборки, декларация об отсутствии неосвобождённого шифрования и профили EAS для TestFlight и iOS-симулятора. Приложение использует только локальные записи, без аккаунта и сервера.

Эти файлы не создают Apple/Expo-аккаунт, сертификаты или доступ к App Store Connect. JavaScript/Hermes-экспорт не является подписанным IPA. Нативная сборка, запуск на iPhone и публикация в TestFlight требуют отдельной проверки после подключения аккаунтов.

В текущей облачной среде нет подключённой авторизации Expo/Apple, а `api.expo.dev` блокируется сетевой политикой. Команды сборки выше рассчитаны на ваш компьютер с доступом к сервисам Expo/Apple. Локальная разработка здесь работает в offline-режиме. Для работы EAS в этой среде потребуется отдельно разрешить нужные адреса и безопасно настроить авторизацию; не обходите проверку TLS.
